# Contributing

This repository is designed both as a learning resource and a portfolio project. Contributions that improve clarity, correctness, or educational value are welcome.

## Good First Contributions

- Improve wiring diagrams or add clearer pinout tables
- Add more detailed tuning guides with real observed data
- Improve BOMs with better part alternatives and current prices
- Add analysis scripts or example plots
- Fix bugs in the firmware or improve comments explaining control decisions
- Translate key sections into clearer language

## Guidelines

- Keep changes focused and well-documented.
- Prefer educational clarity.
- If you change control parameters or algorithms, explain *why* in the PR description.
- Test on real hardware when possible and note the platform used.

Open an issue before starting large structural changes.

Thank you for helping make this resource stronger.
